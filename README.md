# Editor Negocio

App Android para editar rápido los videos informativos del negocio.

- Agregar varios videos, recortar cada uno, ordenarlos (▲ ▼) y unirlos.
- Texto en pantalla (arriba, centro o abajo) y logo del negocio en una esquina.
- Música de fondo con volumen ajustable.
- Formatos 9:16 (Estados, Reels, TikTok), 1:1 y 16:9.
- Guarda en la galería (Movies/EditorNegocio) y botón Compartir.

## Descargar el APK

Cada vez que se sube un cambio, GitHub compila la app sola (pestaña **Actions**, tarda unos 5–8 minutos).
Cuando termina con ✅, el APK queda en **Releases** → la versión más reciente → **EditorNegocio.apk**.

Si la compilación sale con ❌: Actions → la ejecución fallida → build → copia el error del paso en rojo y pásaselo a Claude.
